About this app

Mister O1 Invoices is a class project for ISM4421 (Applied AI for Business) at Florida Atlantic University, built by Nicolas Munoz. It rebuilds an invoice tool used at a pizza restaurant (Mister O1, Boca Raton) as a web app.

What it does

  1. Sign in with Google.
  2. Upload an invoice: one PDF, or photos of each page taken with your phone (the app combines them into one PDF).
  3. AI reads it: Anthropic's Claude reads the vendor, invoice number, date, total and the category breakdown.
  4. Rules sort it: each vendor has a rule (for example, a dairy supplier always goes to "Dairy"; Gordon Food Service is split using its category summary page).
  5. You check it: you can edit everything. Sending stays locked until the categories add up to the invoice total to the cent, and the app warns you if the invoice was already sent.
  6. Send: the invoice is logged in the right weekly tab of a test spreadsheet, saved, and emailed only to you, with the PDF attached.

Built with

Netlify (hosting and server functions), Supabase (sign-in, database, file storage), Anthropic Claude API (reading invoices), Google Sheets API (weekly log), Gmail (emails).

Important

This is a student project, not a commercial product. It writes only to a class demo spreadsheet and never emails the restaurant's accounting service.
